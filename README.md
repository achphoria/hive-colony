# HIVE-COLONY

Kantor virtual, 7 lantai, 28 peran. Ini desainnya dulu. Sambungan ke agen AI belum dipasang.

Situs: https://achphoria.github.io/hive-colony/

Buka `index.html` di browser, atau GitHub Pages dari branch `main`, folder `/ (root)`.

## Lantai

1. Lobby, Customer Experience
2. HYROX dan gym
3. Kafe, retail, keselamatan
4. Studio marketing
5. Finance dan HR
6. Lab produk dan server
7. Penthouse, Chief Executive

Karakter memakai satu tubuh. Yang membedakan hanya rambut, pakaian, dan aksesori. Bot penuh digambar sebagai mesin kecil.

Status yang bergerak masih simulasi desain, bukan kerja agen sungguhan. Titik sambungan ada di `assets/agent-link.js`.
