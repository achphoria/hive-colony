# Hive Colony: keputusan desain

## Gaya

- 3D diorama low-poly, mirip Harvest Moon 3D atau Animal Crossing.
- Dinding cutaway ala The Sims: dinding yang menghadap kamera turun otomatis.

## Karakter: Hive Worker

Chibi berhoodie lebah dengan antena, sayap kecil, dan garis cokelat di badan. Setiap divisi dibedakan lewat aksesorinya:

| Divisi | Aksesori |
|---|---|
| CEO | Mahkota |
| Customer XP | Headset |
| Operations | Helm proyek |
| IT & Infra | Kacamata |
| Marketing | Baret |
| Finance | Dasi kupu-kupu |
| Product | Goggles |
| HR & GA | Syal |

Status agent terlihat dari heksagon kecil di atas kepala:

| Warna | Status |
|---|---|
| Oranye | Sedang misi |
| Hijau | Istirahat |
| Biru muda | Mengisi daya |
| Krem | Rapat |

## Siang-malam dan suasana

- Langit bergradasi dari krem ke jingga senja, lalu ke biru malam. Malam hari ditambah bintang, bulan, dan kunang-kunang.
- Lampu ruangan, jendela heksagon, layar, dan lampu taman menyala di malam hari.
- Agent Hybrid tidur dengan animasi "Zzz". Agent Full AI dan Full Tech tetap jaga malam.
- Tamu berhoodie perak datang ke Hive Lobby lewat tangga, dan pintu kaca geser membuka otomatis.
- Audio disintesis dengan Web Audio: musik pentatonik, dengung lebah, dan efek suara.

## Tahap berikutnya

- Koneksi ke AI nyata (misalnya Claude API) supaya misi benar-benar dikerjakan.
- Model karakter dan furnitur buatan Blender untuk kualitas setara game.
